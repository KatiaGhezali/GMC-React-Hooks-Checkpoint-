# Movie Night 🎬

## Overview

Movie Night is a React application that allows users to explore a collection
of movies and TV shows, add new titles, and filter the collection by title
and rating.

## Features

- Display movies and TV shows as cards.
- Show each title's poster, description, and rating.
- Add a new movie or TV show.
- Search for titles by name.
- Filter titles by minimum rating.
- Display a message when no movies match the filters.
- Responsive layout for desktop and mobile screens.
